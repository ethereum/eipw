markdown-re-consecutive-spaces

Prose does not contain inappropriate consecutive spaces.

Examples

error[markdown-re-consecutive-spaces]: prose must not contain consecutive spaces
  --> input.md
   |
16 | This sentence has  two spaces.
   |                  ^^
   |
   = info: the pattern in question: ` {2,}`

Explanation

Use one space between words in prose. The lint ignores inline code, fenced code blocks, HTML, link URLs, and the two trailing spaces Markdown uses to request a hard line break.
