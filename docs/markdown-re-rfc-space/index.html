markdown-re-rfc-space

RFCs are referenced using exactly one space between the prefix and number.

Examples

error[markdown-re-rfc-space]: RFCs must be referenced with exactly one space (for example, `RFC 2119`)
  --> input.md
   |
27 | This requirement comes from RFC-2119.
   |                             ^^^^^^^^
   |
   = info: the pattern in question: `(?i)\brfc(?:-?[0-9]+|(?:\s{2,}|[^\S ])[0-9]+)\b`

Explanation

Write references as RFC 2119, rather than RFC2119, RFC-2119, or with multiple or non-space whitespace characters.
